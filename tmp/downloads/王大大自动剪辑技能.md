# remotion-vox — 用 Claude Code + Remotion 出 Vox 风格特效片

把"选题脚本 → 一条带动态特效的 mp4"这条装配线固化下来。核心是**你用自然语言描述意图,Claude Code 去写/改 Remotion(React)代码**,你只在 Remotion Studio 里点几下调位置、存值。产出的是高辨识度的 Vox 杂志风动态图形,正好补口播视频"空镜不够、数据/地图/图表段干巴巴"的短板。

> 本 skill 自带一套**能直接跑的项目模板**在 `template/`,别从零让 Claude 重搭。每次出片 = 复制模板 → 改 `src/config.ts` 的脚本时间线 → 塞素材 → 预览 → 渲染。

## 六条铁律(Vox 观感 + 不返工,任何时候别破)

1. **先写台词,再配画面**。永远从"一句旁白 → 一个视觉 beat"的**脚本表**出发(见 `template/script-table.example.md`),不要先做画面再硬凑词。
2. **视觉系统全片锁死**:同一张背景 + 同一套字体 + 同一组强调色(模板里是招牌红 `#E4572E`)。每个场景**只换中景/前景的 cutout**,背景锁定才有"一镜到底"的 Vox 感。
3. **三层结构**:背景层(锁定)+ 中景层(黑白半调人物/主体弹入)+ 前景层(建筑/形状/图表)。`template/src/Scene.tsx` 已实现。
4. **半调是"图"不是"代码"**:cutout 的黑白半调(halftone)网点质感由**生图工具预处理进 PNG**,不在 Remotion 里做。Remotion 只负责排版、弹入动画、偏移红描边。透明底 PNG 丢进 `public/scenes/<场景>/`。
5. **带意图地做动画,但别手写函数**:底层只用 `spring`(弹出)+ `interpolate`(位移/淡入),模板已封好。你只需用大白话说"让白宫先弹进来,然后特朗普和另一个人错开半拍跟上,每个背后给一道偏移红描边"——让 Claude 去调参数,别自己写代码。
6. **Studio 里调完的数值必须 Save**。在 Remotion Studio 用 prop 面板调 scale / XY 位置后,**不 Save 就不保留**,这是最容易白调的坑。

## 前置(要用先确认)

- **Node.js**:已装(`node -v` 应 ≥ 18)。
- **Remotion 依赖**:进项目目录 `npm install` 一次即可,模板 `package.json` 已列好(`remotion` / `@remotion/cli` / `@remotion/media-utils` / `react`)。首次渲染 Remotion 会自动拉一个无头 Chromium。
- **ffmpeg**:已装(Remotion 渲染 mp4 用;模板也可直接输出)。
- **cutout / 背景图的来源**:任选——① 直接让 Claude Code 调**生图 MCP**(视频里用的是 Magnific / Higgsfield 的 MCP 连接器,`设置 → 连接器 → 自定义` 粘 MCP server 地址,属付费);② 或你自己在别处生好透明底 PNG 拖进 `public/scenes/`。**MCP 不是必须**,没有就手动准备图。
- **配音**:视频原版用 ElevenLabs 英式音色——**对中文不适配**。你用**中文 TTS 或自己录的口播音轨**,导出 mp3 放进对应场景文件夹即可,其余流程不变。

## 项目结构(每次出片复制 `template/` 得到)

```
my-video/
├─ package.json          # 依赖 + 命令(studio / render / still)
├─ remotion.config.ts
├─ src/
│  ├─ config.ts          # ★你主要改这里:全局视觉 + scenes 脚本时间线
│  ├─ Scene.tsx          # 三层场景(背景锁定 + cutout 弹入 + 红描边 + 字幕 + 旁白)
│  ├─ VoxVideo.tsx       # 主序列:按每段旁白时长把场景背靠背拼起来
│  ├─ SmokeTest.tsx      # 无素材自检合成
│  └─ Root.tsx           # 注册合成
├─ public/
│  ├─ scenes/
│  │  ├─ scene1/  bg.png  trump.png  khamenei.png  narration.mp3
│  │  └─ scene2/  ...     （每个场景一个文件夹;共享背景可复用同一张）

└─ out/                  # 渲染产物
```

## 端到端流程(照这个顺序,把每步的意图讲给 Claude)

1. **复制模板**:把本 skill 的 `template/` 复制成新项目目录(如 `~/Documents/视频工程/<选题>/`),`cd` 进去 `npm install`。
2. **先生成脚本表**:给 Claude 一个选题,让它产出"台词 × 前景 × 中景 × 生图 prompt"的表格(见 `script-table.example.md`)。原则:一句旁白配一个 beat。
3. **锁视觉系统**:在 `src/config.ts` 顶部确认背景/字体/强调色;竖屏还是横屏(`WIDTH/HEIGHT`)。
4. **填 scenes**:把脚本表落进 `src/config.ts` 的 `scenes` 数组——每条写 `durationInSeconds`(=这句旁白时长)、`cutouts`(位置/缩放/交错 delay)、`caption`。**先不放真图也能跑**(用占位块调排版动画)。
5. **备素材**:每个场景一个 `public/scenes/<id>/` 文件夹,放共享背景 + 透明底半调 cutout;把 `config.ts` 里对应 `background`/`src`/`narration` 路径填上。
6. **开预览**:`npm run studio`(= `remotion studio`),或直接跟 Claude 说 "Start the remotion studio for me please"。
7. **调位置**:Studio 里选 `VoxVideo`,用 prop 面板/直接改 `config.ts` 调每个 cutout 的 `x/y/scale/delay`。**调完 Save**。看不到属性面板就让 Claude "give me prop controls for the elements"。报错就丢回一句 "Fix this error please"。
8. **加动画意图**:用大白话让 Claude 调弹入节奏——"错开半拍""弹得再软一点""红描边偏移再大些"。它改的是 `Scene.tsx` 里的 spring config / drop-shadow 偏移。
9. **配音对齐**:把每段中文旁白 mp3 放进对应场景文件夹、填 `narration`。模板会让每个场景**播自己那段旁白、并按其时长占时**,自动背靠背——即视频里 "each scene should start and end on its own narration"。
10. **配乐/音效**(可选):`public/music.mp3` + 打开 `VoxVideo.tsx` 里 `BG_MUSIC` 开关。注:Studio 里拖动预览音频会发卡,**渲染出来是干净的**,别被吓到。
11. **渲染出片**:`npm run render`(默认输出 `out/video.mp4`),或跟 Claude 说 "render VoxVideo as a 1080p mp4 with music and voiceover mixed in"。想把混音放 Premiere 里做,就只渲纯画面。

## 素材从哪来(四档:能用代码画的,就别去找素材)

Remotion 是"用代码生成画面",所以一大半你以为要找的东西**不用找、直接画**。按优先级:

1. **代码组件(零素材,首选)** —— 数字/图表/打字/流程/箭头全走这,见下"组件库"。
2. **矢量图标 / 你的图** —— 具体的物用 SVG 图标(透明、不用抠);你的车/出镜图丢给我,`rembg` 一步抠成透明底。
3. **豆包/即梦视频过场** —— 只有"必须真实感的动态过场"才用,见 `doubao-prompts.md`。
4. **拆脚本表时,我给每个 beat 标来源**(🟢代码 / 🟡豆包 / 你的图),让你一眼知道哪些根本不用管。大部分 beat 是"代码,不用找"。

## 组件库(代码直接画,在场景里加 `component`,零外部素材)

在 `config.ts` 某个场景里写 `component: {...}`,四选一:

| 组件 | 干嘛 | 配置示例 |
|---|---|---|
| `barCompare` | 柱状对比,柱子长起+数字滚动 | `{type:'barCompare', title:'月销量', unit:'万', items:[{label:'1月',value:3},...]}` |
| `typewriter` | 文字逐字蹦出+光标 | `{type:'typewriter', text:'为什么它能卖爆?', cps:7}` |
| `lineGrow` | 折线画出+面积填充+端点强调 | `{type:'lineGrow', points:[12,20,35,78], unit:'k', caption:'累计交付'}` |
| `flow` | 流程/芯片框图,方块依次点亮 | `{type:'flow', title:'三电', nodes:['电池','电控','电机','700km']}` |

一个场景可同时有 `background` / `video` / `component` / `cutouts`,自动按 背景→视频→组件→cutout→字幕 叠在一条时间线。组件实现见 `src/Components.tsx`,要新组件跟我说。

## 视频过场(豆包/即梦)

具体见 `doubao-prompts.md`。要点:只给"必须真实感的过场"用;我负责写提示词 + 接进片子,你只需在即梦网页两下生成+下载(免费额度),或给 API key 让我全自动。生成的 mp4 丢 `public/clips/`,场景加 `video: {src:'clips/xxx.mp4', overlay:0.4}`。

## 抠图(你的照片 → 透明底 cutout)

已装本地 `rembg`(免费、离线)。你给一张带背景的车/人图,我一条命令抠成透明底 PNG 放进 `public/scenes/`,当 cutout 用:
```bash
python3 -c "from rembg import remove; open('out.png','wb').write(remove(open('输入.jpg','rb').read()))"
```
矢量图(SVG)本来就透明,不用抠,直接用。

## 车/AI 内容怎么用(本地化)

- **最实用的用法不是整片**,而是给你的**口播插一段 10~20 秒的 Vox 动态**:讲参数对比就做"数据段"(数字弹入 + 折线图),讲车型/路线就做"地图段",讲发布会时间线就做"图表段"。把这段 mp4 拿进你的剪辑(chengfeng 管线)当 B-roll。
- cutout 换成车、logo、参数框;背景换成你的品牌底色;红描边可换成你的账号强调色(改 `config.ts` 的 `ACCENT`)。
- 配音直接用你口播原声那一句,画面卡着这句的时长走。

## 排错

- **渲染很慢/卡在下载**:首次渲染 Remotion 在拉无头 Chromium,等一次即可,之后有缓存。
- **`staticFile` 找不到图**:资源必须放在 `public/` 下,路径相对 `public/`(如 `scenes/scene1/bg.png`),别写绝对路径。
- **音频在 Studio 里发卡**:正常现象,以渲染产物为准。
- **改了 `config.ts` 时长但总长不对**:总帧数由各场景 `durationInSeconds` 求和自动算(见 `VoxVideo.tsx` 的 `totalDurationInFrames`),改完刷新 Studio 即可。
- **只想要画面、混音去 Premiere**:渲纯 `VoxVideo` 时把 `config.ts` 里 `narration` 和 `BG_MUSIC` 留空,导出无声画面。
