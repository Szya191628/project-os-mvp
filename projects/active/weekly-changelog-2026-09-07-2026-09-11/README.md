# Project OS 周报汇报视频

本目录是根据 `WEEKLY_REPORT_2026-09-07_2026-09-11.md` 生成的独立 HyperFrames 视频工程。

## 内容主线

1. 项目级权限治理
2. 钉钉阶段/最终交付
3. L2/管理员审批门禁
4. 审批后的下游排期与提醒

## 生成与验证

- `index.html`：单文件视频合成
- `script-tokens.json`：显示文本与配音文本的双层脚本
- `vo-spoken.txt`：本地中文配音稿
- `vo-words.json`、`captions.json`：字幕和动效时间轴
- `ledger.json`：场景间统一向左的转场向量
- `assets/`：品牌字体和背景素材

视频内容来自当前项目可验证的周报，不代表钉钉生产环境已经完成真实联调。
