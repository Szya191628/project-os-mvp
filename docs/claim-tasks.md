# 独立任务按部门发布

在“认领任务 → 发布独立任务”发布，不属于项目流程。

- L1/L2 发布时选择全部部门或多个指定部门；指定部门至少勾选一个。
- 只接受当前组织的有效部门。多部门成员命中主部门或任一附属部门即可；不自动包含子部门。
- 发布者可查看自己发布的任务；其他成员只可看到部门范围内的待认领任务。
- 符合部门范围的 L1/L2/L3 成员均可自行认领。服务端对列表、认领操作使用同一部门范围校验，并保留原子抢占，避免重复认领。
- 旧任务默认全部部门，数据库新增字段不影响原有数据。

验证：`pnpm test:claim-tasks`，使用隔离数据验证实际接口的发布、部门范围、角色、组织边界和重复认领。
