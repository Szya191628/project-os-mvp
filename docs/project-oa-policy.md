# 项目 OA 审批配置

- 项目页面的“更多 → OA审批管理后台”，或项目组合页面的同名按钮，可以配置当前项目。
- 配置者须为 L1 或已获当前项目 L2 发布权限的成员。组合入口仅列出可管理项目。
- 审批人、抄送人从 L1 和当前项目有效 L2 管理成员中选择，不因此授予额外项目权限。
- 最多五组审批；每组可勾选多个审批人，按勾选顺序逐人通过，也可上移/下移调整。提交时自动展开为每人一级，上一人通过才进入下一人。抄送可多选，不参与审批。
- 指定审批人后，包括 L1 在内的其他管理者不能代批。抄送人仅查看，审批中心提供“抄送我的”。
- 未指定审批人时保留原有管理层级审批，当前步骤的纯抄送人不可审批。
- 新提交保存当时的策略快照，后续修改不改变进行中的审批。关闭项目策略仍需 OA，改用默认 L2 策略。
- 配置和本地审批不创建钉钉 OA 实例。现有钉钉通知开关与后台服务设置保持不变。

验证：`pnpm test:oa` 使用隔离的数据替身验证配置往返、审批中心归属、越权拒绝和组织边界，不向钉钉发请求。
