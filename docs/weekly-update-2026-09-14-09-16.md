# Project OS 本周更新报告

> 更新周期：2026-09-14 至 2026-09-16（截至当前）

## 一、总体结论

本周主要围绕任务执行、OA 审批、钉钉通知、任务排期、部门权限和项目组合进行了更新。

项目主流程目前已基本打通：

> 任务发布 → 前置依赖判断 → 任务执行 → 交付物提交 → OA 审批 → 任务完成 → 后续任务自动排期

## 二、本周已完成更新

### 1. OA 审批人与通知

- 修复审批通知错误：通知 worker 现在优先读取审批策略中的 `approverMemberIds`，不再重新按项目 L2 成员推送。
- 支持审批人和抄送人配置；抄送人只能查看，不能代替审批。
- 多个审批人按配置顺序逐人审批。
- 增加 Project OS 本地 OA 审批路径，明确区分本地审批和钉钉 OA 审批。
- 增加钉钉审批配置、回调轮询、失败重试和接口用量记录。

### 2. 超期判断与任务交付

- 超期原因不再根据计划日期直接强制要求填写。
- 只有任务执行状态为“到期未完成”时，超期原因才必填。
- “进行中”或刚刚开启的任务可以正常提交交付审批，即使原计划日期已经过去。
- 前端表单和后端校验规则已保持一致。

### 3. 前置任务与后续节点排期

- 后续任务根据前置任务的实际完成情况重新计算开始时间。
- 前置任务未完成时，后续任务保持受阻状态。
- 增加特殊放行审批：经审批后可以先启动当前任务，但被跳过的前置任务仍需后续完成。
- 已发布任务统一使用数据库任务 ID，避免草稿、归档任务或重复任务被错误投影。

### 4. 项目组合任务

- 项目组合中的任务支持绑定已有项目任务。
- 绑定后复用项目任务的详情、进度、交付物和 OA 审批记录。
- 项目组合任务作为流程索引使用，避免复制出第二套执行数据。
- 发布项目组合流程前，要求组合任务完成项目和具体任务绑定。

### 5. 独立认领任务与部门权限

- 独立任务支持指定可认领部门。
- 支持成员的多部门关系，并按成员所属部门校验认领权限。
- 认领任务页面和任务详情中显示“可认领部门”，帮助 L1/L2 区分任务范围。
- 补齐独立任务发布弹窗的提交、取消、关闭、校验和错误提示处理。

### 6. 资源负载与组织同步

- 增加真实资源负载接口，展示成员、部门、项目任务、计划工时、可用容量和超载冲突。
- 增加未来六周负载热力图。
- 支持资源负载 CSV 导出。
- 完善钉钉部门、成员、主管关系和成员多部门同步。
- 完善 L1、项目 L2、L3 和部门主管的访问范围判断。

## 四、尚未完成或需要继续验证的事项

- 钉钉真实生产环境的登录、通知、OA 回调和审批人收件箱需要端到端联调。
- 钉钉通知中的任务一键跳转 Project OS 详情页尚未完全补齐。
- 风险、成本、工时页面仍有示例数据，尚未形成完整的数据录入和审批闭环。
- 物料管理系统目前只有跳转入口，尚未实现双向数据同步。
- 差旅系统和微信小程序尚未开发。
- 当前 Docker 配置主要用于 PostgreSQL；前后端、附件存储、生产环境变量和钉钉密钥仍需单独部署配置。
- 需要最终确认普通成员是“全流程可见”还是“按项目/部门隔离可见”。
